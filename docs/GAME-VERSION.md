# 目标游戏版本要求（重要）

## 结论

本 MOD 的内存地址体系**硬编码**于下列版本的游戏主程序。**换版本必然失效**（面板不出现、或功能错乱、或直接崩溃）：

| 文件 | 版本说明 | MD5 |
|---|---|---|
| 游戏主程序 | 文字修正CHENUEN_c（20120101）.exe | `927941f8f6622b65f1b685e7cd7ef80c` |

> 该 exe 为社区流传的"2012 文字修正版"，是整合包的标准基础版本；发布侧常将其改名为 `CHENUEN_c.exe`（内容不变，MD5 相同）。

## 为什么必须固定版本

面板通过**绝对内存地址**读写游戏数据（城市数组、武将属性、行动标志、引擎闸门等）。这些地址随 exe 编译版本不同而整体漂移。工程内 `docs/addresses.json` 记录了地址定位过程与结论（含大量"定位方法学"沉淀，可供移植到其他版本时参考）。

## 如何自查版本

```bash
md5sum "文字修正CHENUEN_c（20120101）.exe"
# 期望输出：
# 927941f8f6622b65f1b685e7cd7ef80c
```

- **匹配** ⇒ 可以配合本工程产物使用；
- **不匹配** ⇒ 请勿使用本工程的二进制产物（基于其它版本的 bug 报告无效）。
