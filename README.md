# 郑问之三国志 MOD（威力加强版）源码工程

《郑问之三国志》（2001，GAMEARTS）的民间 MOD 工程源码。以**注入式内置面板**为核心，提供游戏内修改器、太守委任、召集/训练等机制，并配套 PC / 安卓双端自动加载链。

> ⚠ **本仓库不包含游戏本体**。构建产物必须配合自备的、**版本匹配**的游戏使用——见 [docs/GAME-VERSION.md](docs/GAME-VERSION.md)（版本不匹配将直接失效）。

## 组件构成

| 组件 | 源码 | 产物 | 说明 |
|---|---|---|---|
| 内置面板 | `src/overlay.c` | `zy_overlay14.dll` | 面板渲染 / 内存读写 / 委任 / 作弊 / 召集 / 训练 / 诊断 |
| d3d11 垫片 | `src/d3d11_proxy.c` + `src/fwd.S` | `d3d11.dll` | 环境感知转发（Wine→DXVK / Windows→系统）+ 面板自动加载 |
| dxgi 垫片 | `src/dxgi_proxy.c` + `src/fwd_dxgi.S` | `dxgi.dll` | 安全转发器（切断"系统组件×DXVK 混搭"事故链） |
| 注入器 | `src/injector.c` | `inject.exe` | 32 位注入器（开发调试用） |

## 目录结构

```
zw3_pk_mod/
├── src/                  源码（C / 汇编桩 / def 导出表）
├── tools/                Python 工具（注入式启动器）
├── docs/                 构建指南 / 版本要求 / 内存地址表
├── build.sh              一键构建脚本
└── build/                构建产物（不入库）
```

## 快速开始

1. **准备工具链**：msys64 + mingw-w64-i686-gcc（安装方法见 docs/BUILD.md）
2. **构建**：Git Bash 中执行 `bash build.sh` → `build/` 下产出四个文件
3. **部署（玩家形态）**：把 `zy_overlay14.dll`、`d3d11.dll`、`dxgi.dll` 复制到游戏目录。
   ⚠ **依赖链注意**：本工程的垫片链依赖 dgVoodoo2 把老游戏的 DirectDraw 调用转到 D3D11
   （游戏目录需有 `DDraw.dll` / `D3DImm.dll` / `dgVoodoo.conf`，即 dgVoodoo2 的 wrapper 文件；
   安卓端对应需要 DXVK 的 `d3d11_real.dll` / `dxgi_real.dll`）。这些第三方组件不在本仓库内，
   请从 dgVoodoo2 / DXVK 官方获取。完整的"解压即玩"部署形态见发布包结构说明（docs/BUILD.md §6）。
4. **注入调试（开发形态）**：
   ```
   ZW3_GAME_EXE=<游戏主程序路径> python tools/zw3_launcher.py start
   ```

## 开发与开源统一（重要约定）

本目录**既是开源仓库、也是本地开发的唯一源码源头**——两者是同一份文件，不存在"开源版 / 本地版"两份代码各自漂移的问题：

- 所有对面板 / 垫片 / 注入器的修改都在 `src/` 直接进行，改完重新 `build.sh` 构建；
- 构建产物从 `build/` 部署（游戏目录 / 发布包），产物本身不入库（见 .gitignore）；
- **未开源的部分是"外部增量"**（既不依赖本仓库、也不被本仓库依赖）：
  - 立绘 / 素材重绘工具链（在游戏素材侧独立处理）；
  - 手机端推送 / 中继工具（独立部署工具）；
  - 历史版本档案与逆向定位过程的中间脚本。

  这些工具**继续留在开发环境原地**、正常参与日常开发与发布流程，只是**不纳入版本库**：
  本仓库 `git init` 的范围即本目录（`zw3_pk_mod/`），私有件位于本目录之外，结构上不可能被误提交。
  任何私有件的改动都不会触碰本仓库文件，本仓库也无需它们即可完整构建。
